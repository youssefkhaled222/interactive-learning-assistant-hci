# Interactive Learning Assistant for Children

**MSA University — CS484 Human-Computer Interaction**  
**Fall 2026 | HCI Project**

## Project Overview

An interactive educational application designed for children aged 5–10.

The application proposes a camera-based "Find the Object" game that uses real-object detection and tracking to support two touch-free interaction techniques:

- **Eye Tracking:** Selecting an on-screen object by maintaining gaze on it.
- **Hand Gestures:** Controlling an on-screen pointer and using a pinch gesture to select an object.

The project aims to compare these techniques in terms of usability, accuracy, task completion time, engagement and satisfaction.
